archival-htr

Historical manuscript corpus query interface

Search performs vector similarity search across all indexed manuscript chunks. Enter a phrase or topic and the index returns the most semantically related passages, ranked by relevance score. Each result shows the source document, a score bar, and a short excerpt. Use the Results slider to control how many matches are returned, and the optional filters to narrow results to a specific source document or metadata category.

Ask extends Search by adding a language-model reasoning step. The index retrieves the top N relevant chunks (controlled by the Context chunks slider — more chunks means broader coverage but slower responses), then passes them to the model, which reads them together and synthesises a single natural-language answer. Use Ask when you want an interpreted response that draws on evidence from across multiple documents, rather than a ranked list of raw passages.

Query skips vector retrieval entirely. You select a specific source document from the dropdown and the model answers your question using that document's complete stored transcript as context. Unlike Ask, which samples the most relevant chunks from anywhere in the index, Query gives the model access to every word of the chosen document — making it the best choice when you already know which petition to interrogate and want nothing left out.
